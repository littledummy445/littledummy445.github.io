# Portfolio & Project Showcase

A modern, responsive personal portfolio and project showcase built with a custom **Liquid Glass UI**, smooth CSS animations, and secure glassmorphic design principles. Hosted live via **GitHub Pages**.

## Features

* **Glassmorphic UI**: Features blur effects, glowing background orbs, custom gradients, and smooth hover elevation cards.
* **Project Ecosystem**: Direct links to hosted and open-source systems including remote desktops, AI chat applications, and containerized emulators.
* **Instant Deployment Badges**: Includes direct "Open in GitHub Codespaces" integration for immediate cloud-based testing.
* **Content Protection**: Built-in script prevention for basic context-menu and text selection restrictions.
* **Embedded Assistant**: Integrated Chatbase AI conversational widget.

---

## Structure

* `index.html`: The core single-page application containing all styles, layout structure, and repository showcase cards.

---

## Technologies Used

* **HTML5 & CSS3** (Custom Properties, Flexbox, Grid, Keyframes)
* **JavaScript** (UI interaction blockers and third-party script injectors)
* **GitHub Pages** (Static hosting)
